# HyperOS 设计与开发平台全景图

把《HyperOS 设计与开发平台全景图》总表做成一页可视化。分类按「大分类 → 子分类 → 条目」排列，可以用状态筛选。

## 开发

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 更新数据

分类数据在 `data/panorama.json`。改完保存，刷新页面即可。

## 状态怎么显示

- 原文里的「已有」显示为「已完成」。
- 子分类标了「进行中」、条目本身没写状态的，显示为「进行中」。
- 没有写状态、所属子分类也不是「进行中」的，显示为「已完成」。

页面文字来自这张总表。飞书子页、组件规格、示意图、链接、负责人和时间不在这份数据里。「㝵航」「Empty Stat」按原文显示。
